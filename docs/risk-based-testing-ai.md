# Risk-Based Testing Using AI

## Concept
AI helps identify high-risk areas based on:
- Historical defect density
- Code complexity signals
- User journey criticality

---

## Risk Scoring Model

AI assigns risk score based on:
- Feature complexity (0–10)
- Business impact (0–10)
- Change frequency (0–10)

---

## Example

| Feature | Risk Score | Action |
|--------|-----------|--------|
| Payment | 9.5 | Full regression |
| Profile UI | 4.2 | Smoke tests |

---

## Benefit
- Smarter regression selection
- Reduced execution time
- Focused QA effort
