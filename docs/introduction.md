# Introduction to AI in QA

## Overview
Artificial Intelligence is transforming QA from execution-heavy roles to **intelligence-driven quality engineering**.

---

## Traditional QA vs AI-Augmented QA

### Traditional QA
- Manual test case creation
- Static regression suites
- Reactive defect analysis

### AI-Augmented QA
- Dynamic test generation using LLMs
- Predictive defect analysis
- Risk-based test prioritization
- Automated exploratory testing ideas

---

## Where AI Fits in QA Lifecycle

### 1. Requirements Phase
- Generate ambiguity questions
- Identify missing acceptance criteria

### 2. Test Design Phase
- Generate test scenarios
- Expand edge cases

### 3. Execution Phase
- Assist automation scripting
- Suggest missing validations

### 4. Defect Phase
- Cluster similar bugs
- Suggest root cause hypotheses

---

## Key Principle
AI is a **co-pilot**, not an authority.
QA owns validation.
