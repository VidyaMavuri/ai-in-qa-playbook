# API Test Generation Prompts

## Example 1: Auth API
Generate test cases for authentication API supporting JWT, refresh tokens, and MFA. Include:
* Positive scenarios
* Invalid credentials
* Token expiry cases
	•	Security edge cases Return in table format.
---

## Example 2: Payment API
Create test cases for payment API supporting retries and idempotency keys. Focus on:
* Duplicate transaction prevention
* Failure recovery
	•	Partial payment scenarios
---

## Example 3: Rate Limiting
Generate test cases for API rate limiting with thresholds per user and IP. Include stress and abuse scenarios.
